## Start a New RZ FSP Project

1. Select an MPU or evaluation kit from the [RZ Product Portfolio](https://www.renesas.com/en/products/microcontrollers-microprocessors/rz-mpus).
2. Download the development environment from [RZ FSP Releases](https://github.com/renesas/rz-fsp/releases).
3. Follow the [RZ FSP Documentation](https://renesas.github.io/rz-fsp/).
4. Find a reference project for your kit or peripheral in [RZ Example Projects](https://github.com/renesas/rz-fsp-examples).

## RZ Flexible Software Package

The **RZ Flexible Software Package** provides a unified software package for the RZ/A, RZ/G, RZ/N, RZ/T, and RZ/V series.

It includes:

- Board support packages
- Peripheral drivers
- Middleware
- RTOS integration
- Configuration and code-generation support
- Security and connectivity components
- Software support for compatible RZ evaluation kits

[Explore the RZ FSP repository](https://github.com/renesas/rz-fsp)

Before requesting assistance:

1. Review the documentation for your RZ device, evaluation kit, and software package.
2. Search existing issues in the relevant source repository.
3. Open a GitHub issue where issue tracking is enabled.
